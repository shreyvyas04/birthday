# Music (optional)

The site never autoplays. A small round button in the top-right corner lets the visitor play or pause.

To add music:

1. Put a properly licensed audio file here and name it `birthday-song.mp3`
   (or change `music.src` in `lib/birthday-content.ts`).
2. Only use music you own, have written permission to use, or that carries a licence allowing this use
   (for example royalty-free or Creative Commons tracks, with any required credit noted in the README).
   Do not use a commercial song you have not been licensed to use.
3. Keep the file small (a loop of 1-3 minutes, under about 3 MB).

If the file is missing, the button shows a friendly "Music can be added later" note.
To remove music completely, set `music.enabled` to `false`.
